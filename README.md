# Comic Edge

Posterised colour with inked outlines traced from the footage — a clean comic/cel-shaded look with no model required.

An [azphalt](https://github.com/HereLiesAz/azphalt) extension for
[Guillotine](https://github.com/HereLiesAz/Guillotine).

- **Package id** — `com.hereliesaz.azphalt.comic-edge`
- **Version** — 1.0.0
- **Kind** — asset (ISF fragment shader)
- **Tags** — `shader`, `stylize`, `comic`, `cel-shade`, `posterize`, `outline`, `one-click`

## Controls

| Parameter | Label | Range | Default |
| --- | --- | --- | --- |
| `levels` | Colour levels | 2.0 – 12.0 | 5.0 |
| `ink` | Ink | 0.0 – 1.0 | 0.7 |

## Install

Open **Azphalt Store** inside Guillotine, find *Comic Edge*, and tap **Install**. The effect is
applied to the selected clip.

To install manually, pack this directory as a `.azp` (a plain ZIP with `manifest.json` at the root)
and side-load it from the store's *Install from file* action.
